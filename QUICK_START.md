## ⚡ Cepat Test (5 Menit)

### Di Browser Desktop
1. **Buka** website: http://localhost:8000
2. **Tekan** F12 untuk buka Developer Tools
3. **Tekan** Ctrl+Shift+M untuk Responsive Mode
4. **Pilih** device: iPhone, iPad, Galaxy Tab
5. **Perhatikan** layout berubah sesuai ukuran layar
6. **Test** tombol dan form di berbagai ukuran

### Di Smartphone Asli
1. **Buka** website http://192.168.x.x:8000 (ganti IP)
2. **Rotate** dari portrait ke landscape
3. **Coba klik** tombol dan isi form
4. **Perhatikan** bahwa semuanya terlihat baik

## 🆘 Issue? Coba Ini

| Issue | Solution |
|-------|----------|
| Layout terlihat aneh | Clear cache (Ctrl+Shift+Del) |
| Text terlalu kecil | Pinch zoom (2 jari) atau zoom browser |
| Button tidak bisa diklik | Tap di tengah button dengan tepat |
| Image terlihat stretched | Refresh page (Ctrl+F5) |

---

## 💡 Pro Tips

1. **Responsive Mode:** Ctrl+Shift+M di browser (cepat test)
2. **Device Selection:** Pilih iPhone, iPad, Galaxy untuk akurat
3. **Orientation:** Klik ikon rotate untuk test landscape
4. **Slow 3G:** Pilih Slow 3G di DevTools untuk test performance
